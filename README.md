# FLAG SERIES Website

Statische Shop-Vorlage für www.flagseries.de mit HTML, CSS und JavaScript.

## Enthalten
- `index.html` Hauptseite
- `css/style.css` Design
- `js/app.js` Produktvarianten, Preisberechnung, Rabattlogik
- `assets/images/` Produktbilder
- `legal/` Platzhalterseiten für Impressum, Datenschutz, AGB, Widerruf

## Preise
- 39,00 € pro 50er Box inkl. 19% MwSt.
- Ab 10 Boxen automatisch 10% Rabatt

## Zahlung
Aktuell erstellt der Button eine Bestell-E-Mail. Für echte Online-Zahlung brauchst du ein Backend oder einen Zahlungsanbieter-Checkout, z.B. PayPal Checkout, Stripe, Mollie oder Shopify/WooCommerce.

## Deployment
Dateien per FTP/SFTP in den Webspace deiner Domain laden. Startdatei ist `index.html`.
